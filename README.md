# Moldkrathong

เกมปั้นกระทงกับก้อนนุ่ม Moldable แล้วไปลอยในแผนที่จริง (เว็บสำหรับมือถือ)

- เป็นไฟล์เว็บธรรมดา ไม่ต้อง build: ย้ายทั้งโฟลเดอร์ไปวางบนเซิร์ฟเวอร์ไหนก็ได้ที่เปิดผ่าน https
- แก้สถานที่ ลิงก์ IG และแผนที่ได้ที่ `js/config.js`
- แผนที่: ELEMNT Cartographer (ฟรี ไม่ต้องใช้คีย์) ต้องแสดงป้าย "Powered by ELEMNT" และเครดิต OpenStreetMap ห้ามซ่อน
- ไลบรารี (three.js, MapLibre, PMTiles) อยู่ใน `lib/` ไม่ต้องโหลดจากที่อื่น

## โครงสร้าง
- `index.html` หน้าเดียวทั้งเกม · `css/style.css` หน้าตา
- `js/app.js` หน้าจอและปุ่ม · `js/map.js` แผนที่ · `js/sculpt.js` ห้องปั้น 3D
- `js/characters.js` ก้อนนุ่ม 5 ตัว (วาด 2D) · `js/chardata.js` รูปทรงจาก brand book

## ขั้นตอนที่ทำแล้ว
1. แผนที่ + 3 จุด (บ่อ Moldable, สะพานพระราม 8, สวนรถไฟ) · ห้องปั้น (ทรงเริ่มต้น 9 แบบรวมทรงกระทง, ปั้น 7 แบบ, ลงสี, ตา/ปาก/สติกเกอร์, ธูป เทียน ดอกไม้ เหรียญ พวงมาลัย ใบตองพับ, ย้อนกลับ)
2. บันทึกรูป PNG แบบไม่มีพื้นหลัง หรือพื้นหลังจุดที่ลอย (ขนาดโพสต์ IG 1080×1350) — `js/card.js`
3. ลอยจริง: อธิษฐาน (ไม่เกิน 60 ตัว, เลือกให้คนอื่นเห็นหรือไม่) · หน้าแม่น้ำ 2.5D (`js/river.js`) · รายงาน 3 ครั้งซ่อนอัตโนมัติ · กระทงฟรี 5 ใบ (`assets/free/*.png` เปลี่ยนเป็นไฟล์ของทีมได้ ชื่อไฟล์เดิม ขนาด 600×600 พื้นโปร่งใส) · แชร์สตอรี่ 1080×1920
4. แอดมิน: `admin.html` ใช้รหัสแอดมิน (ซ่อน/แสดง/ลบ/บล็อกเครื่อง/ล้างทั้งจุด)

## ฐานข้อมูล
Supabase โปรเจกต์ `moldkrathong` ตั้งค่าที่ `js/config.js` (ปล่อยว่าง หรือเติม `?local=1` ท้ายลิงก์ = โหมดทดสอบในเครื่อง)
