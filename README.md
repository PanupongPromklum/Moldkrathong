# Moldkrathong

เกมปั้นกระทงกับก้อนนุ่ม Moldable แล้วไปลอยในแผนที่จริง (เว็บสำหรับมือถือ)

- เป็นไฟล์เว็บธรรมดา ไม่ต้อง build: ย้ายทั้งโฟลเดอร์ไปวางบนเซิร์ฟเวอร์ไหนก็ได้ที่เปิดผ่าน https
- แก้สถานที่ ลิงก์ IG และแผนที่ได้ที่ `js/config.js`
- แผนที่: ELEMNT Cartographer (ฟรี ไม่ต้องใช้คีย์) ต้องแสดงป้าย "Powered by ELEMNT" และเครดิต OpenStreetMap ห้ามซ่อน
- ไลบรารี (three.js, MapLibre, PMTiles) อยู่ใน `lib/` ไม่ต้องโหลดจากที่อื่น

## โครงสร้าง
- `index.html` หน้าเดียวทั้งเกม · `css/style.css` หน้าตา
- `js/app.js` หน้าจอและปุ่ม · `js/map.js` แผนที่ · `js/sculpt.js` ห้องปั้น 3D
- `js/characters.js` ก้อนนุ่ม 5 ตัว (วาด 2D) · `js/chardata.js` รูปทรงจาก brand book
