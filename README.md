# Moldkrathong

เกมปั้นกระทงกับก้อนนุ่ม Moldable แล้วไปลอยในแผนที่จริง (เว็บสำหรับมือถือ)

- เป็นไฟล์เว็บธรรมดา ไม่ต้อง build: ย้ายทั้งโฟลเดอร์ไปวางบนเซิร์ฟเวอร์ไหนก็ได้ที่เปิดผ่าน https
- แก้สถานที่ ลิงก์ IG และแผนที่ได้ที่ `js/config.js`
- แผนที่: ELEMNT Cartographer (ฟรี ไม่ต้องใช้คีย์) ต้องแสดงป้าย "Powered by ELEMNT" และเครดิต OpenStreetMap ห้ามซ่อน
- ไลบรารี (three.js, MapLibre, PMTiles) อยู่ใน `lib/` ไม่ต้องโหลดจากที่อื่น

## โครงสร้าง
- `index.html` หน้าเดียวทั้งเกม · `css/style.css` หน้าตา
- `js/app.js` หน้าจอและปุ่ม · `js/map.js` แผนที่ · `js/sculpt.js` ห้องปั้น 3D
- `js/characters.js` ก้อนนุ่ม 5 ตัว (วาด 2D) · `js/chardata.js` รูปทรงจาก brand book

## ขั้นตอนที่ทำแล้ว
1. แผนที่ + 3 จุด (บ่อ Moldable, สะพานพระราม 8, สวนรถไฟ) · ห้องปั้น (ทรงเริ่มต้น 9 แบบรวมทรงกระทง, ปั้น 7 แบบ, ลงสี, ตา/ปาก/สติกเกอร์, ธูป เทียน ดอกไม้ เหรียญ พวงมาลัย ใบตองพับ, ย้อนกลับ)
2. บันทึกรูป PNG แบบไม่มีพื้นหลัง หรือพื้นหลังจุดที่ลอย (ขนาดโพสต์ IG 1080×1350) — `js/card.js`
3. ลอยจริง: อธิษฐาน (ไม่เกิน 60 ตัว, เลือกให้คนอื่นเห็นหรือไม่) · หน้าแม่น้ำ 2.5D (`js/river.js`) · รายงาน 3 ครั้งซ่อนอัตโนมัติ · กระทงพร้อมลอย 5 ใบ (`assets/free/*.png` + รายชื่อใน `READY` ของ `js/config.js` เปลี่ยนเป็นไฟล์ของทีมได้ ขนาด 600×600 พื้นโปร่งใส) · "เก็บไว้ก่อน" เก็บในเครื่องได้ 8 ใบ ลอยแล้วหายจากที่เก็บ · แชร์สตอรี่ 1080×1920
4. แอดมิน: `admin.html` ใช้รหัสแอดมิน (ซ่อน/แสดง/ลบ/บล็อกเครื่อง/ล้างทั้งจุด)

## ฐานข้อมูล
Supabase โปรเจกต์ `moldkrathong` ตั้งค่าที่ `js/config.js` (ปล่อยว่าง หรือเติม `?local=1` ท้ายลิงก์ = โหมดทดสอบในเครื่อง)

## หน้าตา (Morph night pop)
- สีทั้งหมดอยู่ด้านบนของ `css/style.css` (ใช้สี Morph DS; `--warm` สีแสงเทียนเป็นค่าที่เสนอเพิ่ม)
- ไอคอน 2 โทน: `js/icons.js` · ฉาก 2.5D (ท้องฟ้า พระจันทร์ โคมลอย น้ำ ใบบัว): `js/scene.js`
- ปุ่มเครื่องมือทุกปุ่มขนาด 56px เท่ากัน · ปุ่มย้อนกลับ/เสร็จแล้วอยู่ใกล้นิ้วโป้ง · หน้าต่างต่างๆ เลื่อนขึ้นจากด้านล่าง

## เสียง
- เสียงกดและเพลงสร้างสดใน `js/audio.js` (ไม่ใช้ไฟล์) เพลงเป็นทำนองรำวงที่แต่งใหม่ ไม่ใช่เพลงที่มีลิขสิทธิ์
- ถ้ามีไฟล์เพลงที่ได้สิทธิ์แล้ว วางที่ `assets/music.mp3` เกมจะเปิดไฟล์นั้นแทนอัตโนมัติ (เสียงเบา 25%)
- ปุ่มเปิด/ปิดเสียงอยู่หน้าแรกและแถบบนของแผนที่

## ออกเวอร์ชันใหม่
ทุกไฟล์ JS อ้างกันด้วย `?v=13` และ `index.html` ใช้ `?v=13` ถ้าแก้ไฟล์ ให้เพิ่มเลขทุกที่พร้อมกัน (กันมือถือใช้ไฟล์เก่าปนไฟล์ใหม่)

## ปั้นจากรูป (`js/photo.js`)
แท็บ "ทรง" → "จากรูป": ตัดพื้นหลังจากสีขอบรูป → เก็บวัตถุชิ้นใหญ่สุด → อ่านเงาเป็นรูปทรง → พองเป็นก้อนดิน → ด้านหน้าแปะลายคมจากรูป (texture 512px) ข้าง/หลังเป็นสีพาสเทลเรียบ พู่กันวาดลงลายได้ ทำงานในเครื่องทั้งหมด รูปไม่ถูกอัปโหลด

## แปรง
แถบแนวตั้งข้างจอ: ซ้าย = ขนาด (ช่วงเล็กละเอียดขึ้น) + ปุ่มสมมาตร, ขวา = แรง · เลื่อนแล้วมีวงกลมตัวอย่างขนาดกลางจอ

## กันรูปไม่เหมาะสม
- ตรวจบนเครื่องด้วย NSFWJS (`lib/nsfw/`, โมเดล MobileNetV2 ~2.6MB โหลดเฉพาะตอนกด "จากรูป"): ตรวจรูปก่อนปั้น และตรวจภาพกระทงอีกครั้งตอนลอย บล็อกเมื่อ Porn > 50% หรือ Hentai > 60%
- กระทงจากรูปถูกบันทึก `from_photo` + คะแนน `nsfw` · หน้าแอดมินมีตัวกรอง "จากรูป" เรียงคะแนนน่าสงสัยก่อน
- ถ้าตัวตรวจโหลดไม่ได้ จะปล่อยผ่าน (ยังมีรายงาน 3 ครั้งซ่อนเอง + แอดมิน)
